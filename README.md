# Soyoung Park Photography

포토그래피 포트폴리오 웹사이트

## 도메인
soyoungpark.kr

## 프로젝트 구조

```
soyoungpark-photography/
├── index.html              # 메인 페이지
├── about.html              # 소개 페이지
├── contact.html            # 연락처 페이지
├── collections/            # 컬렉션 목록
├── gallery/                # 개별 갤러리 페이지
├── assets/
│   ├── css/               # 스타일시트
│   ├── js/                # JavaScript 파일
│   └── images/            # 이미지 파일
│       ├── thumbnails/    # 썸네일
│       └── fullsize/      # 원본 이미지
└── netlify.toml           # Netlify 설정
```

## 개발 가이드

### 로컬 개발
1. Live Server 또는 Netlify Dev 사용
2. `netlify dev` 명령어로 로컬 서버 실행

### 배포
- Netlify에 자동 배포 설정
- 도메인: soyoungpark.kr

## 기능
- 반응형 갤러리
- 라이트박스 이미지 뷰어
- 컬렉션 필터링
- 이미지 지연 로딩
